# FinIF Experiment 3 human annotation

Blind human annotation interface for 50 test items and three sampled constraints per item (150 constraint judgments total).

- Response model: `Qwen/Qwen3.5-27B`
- Human labels: `pass` / `fail`
- Machine predictions and comparison-arm assignments are intentionally excluded from all published files.
- Dataset version: `finif-experiment3-qwen35-27b-20261006-v1`
